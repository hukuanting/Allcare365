# 病患疾病網絡

入口：/disease-network?patient_id=<病患ID>；工作空間導覽、病歷頁及風險頁均可進入。

沿用正式風險分析 API、病患選擇、存取控制與請求取消機制。每位病患的節點狀態由其模型結果產生，連線由模型目錄 required_input_keys 共用的臨床因子產生；排除僅年齡／性別交集。沒有新增或混算個人罹病機率。節點可鍵盤選取，側欄呈現已計算模型、相關領域及待補資料。

這個版本的延伸探索是模型共用輸入關聯，尚未建立疾病因果推論或跨模型機率校準。可作為下一輪研究推論引擎的可追溯基礎。一般心血管／代謝／腎臟連結的官方背景：
- https://www.niddk.nih.gov/health-information/kidney-disease/chronic-kidney-disease-ckd/causes
- https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems/heart-disease-stroke
