# 資料集說明
- 使用SQLite格式儲存之生理訊號。
- 本資料集包含 anon_1.db 及 anon_1-1.db，兩檔案為相同病人之不同資料分批。

# 檔案說明

本專案包含三個主要檔案，分別用途如下：

---

## 1. data_sheet.md
- 說明所有生理訊號資料的格式、欄位、型態、單位、取樣率等。
- 供資料庫設計、資料匯入、資料解析等技術人員參考。
- 包含各類型訊號的表格定義與欄位說明。

## 2. sqlite_usage.md
- 說明如何使用 SQLite 資料庫儲存、瀏覽、查詢、匯出生理訊號資料。
- 包含資料表結構範例、查詢語法、匯出 CSV 步驟、推薦圖形介面工具（DB Browser for SQLite、DBeaver）。
- 適合技術人員、資料分析師、臨床人員快速上手。

## 3. 資料庫檔案（xxx.db）
- 實際儲存生理訊號資料的 SQLite 資料庫檔案。
- 檔名建議以 xxx.db 命名，例如 lsp_data.db、patient_202510.db。
- 可用 DB Browser for SQLite 或 DBeaver 開啟、查詢、匯出。

## 4. stat 資料夾
- 用於存放本資料集的時間分佈相關統計資料。
- 內容可能包含各類型訊號的時間分佈、統計分析結果等。
- 方便資料分析、品質檢查與研究使用。

---

如需詳細格式與操作，請參考 data_sheet.md 及 sqlite_usage.md。
