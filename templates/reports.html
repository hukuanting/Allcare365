🚀 API Endpoints

The Reports API provides RESTful endpoints for programmatic access to reporting functionality:

  • GET /api/v1/reports/templates/ - List all report templates
  • GET /api/v1/reports/executions/ - List report executions
  • GET /api/v1/reports/favorites/ - Manage favorite reports
  • GET /api/v1/reports/analytics/ - Report analytics and statistics
  • GET /api/v1/reports/builtin/ - Built-in report generators
